# Repository Maintenance Proposals Under Review

Keep TheKnowledge proposals awaiting a decision here.

Top-level files in this directory are TheKnowledge's actionable proposal
records. The `imported-ecrs/` subdirectory is raw intake, not the final home
for deconflicted work. When an imported ECR becomes actionable, promote or
extend a top-level proposal here and record the mapping in the imported-ECR
deconfliction index.

Keep the matching starter template README unchanged unless the template
wording or examples are being revised.
