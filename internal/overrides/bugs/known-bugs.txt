  Summary: Codex sandboxed commands fail on this EL9 host because the system

  Impact: non-escalated `exec_command` and `apply_patch` paths fail with

  Current status: local reproduction is fixed under `codex-cli
  0.117.0-alpha.17`, but this bug stays open until the same sandbox fix ships
  in a non-alpha/mainline Codex release.
  Detailed record: `open/bubblewrap-argv0-sandbox-incompatibility.txt`
