Repository Maintenance Resolved Bugs

Record resolved TheKnowledge maintenance bugs here. Keep

*

  2026-03-25T15:15:56-07:00
  Summary: Feedback-branch guidance was underdocumented for active
  submodule users, so contributors could mistake a sibling checkout for the
  intended reporting path and skip restoring the submodule afterward.
  Root cause: TheKnowledge documented the purpose of `Feedback` but not the
  exact active-submodule operating sequence for capturing the current state,
  switching to `Feedback`, reporting there, and switching back afterward.
  Resolution: added a submodule-workflows specification, updated TheKnowledge
  and downstream docs to spell out the active-submodule `Feedback` flow and
  the review-before-adopt submodule-upgrade flow, and revalidated the
  documentation wiring plus the full required check suite.

*

  2026-03-25T14:28:19-07:00
  Summary: The cached quality-gate helper crashed in active submodule
  checkouts because its default `.git/...` cache path was resolved against
  the worktree `.git` file instead of the real git directory.
  Root cause: `scripts/run_quality_gate_cached.py` joined the configured
  `.git/project-quality-cache.json` path directly under the repo root and
  then called `mkdir` on its parent, which fails when `.git` is a file in a
  submodule or separate-git-dir worktree.
  Resolution: normalized `.git/...` cache paths through `git rev-parse
  --git-dir`, added regression coverage for a separate-git-dir repository,
  and revalidated the full required quality gate after the fix.
