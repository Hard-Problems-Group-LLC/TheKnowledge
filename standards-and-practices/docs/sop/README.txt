SOP Subtree
===========

This subtree is for language- and technology-specific SOPs that extend the
core repository-wide standards.

- `guidelines`: SOPs for high-level system and user interface design.
- `languages/`: SOPs for specific programming languages.
- `technologies/`: SOPs for frameworks, platforms, tools, and services.
- `techniques/`: SOPs for higher-level techniques, such as what should be
  done when a new web service is required.

Keep these SOPs implementation-oriented and reusable across projects.
When you add a new SOP, keep it generic enough for submodule distribution and
avoid project- or operator-specific naming.
