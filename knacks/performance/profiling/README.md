# Profiling

Load this area when a task needs a repeatable measurement workflow rather than
an intuition-led guess about slowness.

Current stock documents:

- `WebPageLoadAndRenderProfiling.knack.md` for building project-local
  utilities that measure when a web page becomes structurally complete,
  semantically ready, and visually settled, typically with Playwright plus
  lightweight DOM-side instrumentation.
