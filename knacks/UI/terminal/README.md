# Terminal Knacks

This directory is reserved for terminal-focused knack documents.

This directory holds focused `.knack.md` files for terminal protocols,
emulator behavior, terminal libraries, and API references.

Start with the document that matches the layer you are touching:
- `ansi.knack.md` for the control-sequence grammar shared across many
  terminals and emulators.
- `vt100.knack.md` for DEC VT100-era behavior and compatibility limits.
- `xterms.knack.md` for modern xterm-family emulator behavior.
- `curses.knack.md` for the portable screen-library model.
- `curses.api.C.knack.md` for the generic curses C API.
- `curses.api.Python.knack.md` for Python's `curses` module and helpers.
- `ncurses.knack.md` for the dominant open implementation and its
  extensions.
- `ncurses.api.C.knack.md` for the ncurses C API and extension boundary.
- `ncurses.api.CPP.knack.md` for the shipped ncurses C++ wrapper layer.
